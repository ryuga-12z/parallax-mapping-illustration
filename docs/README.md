## 使い方（ローカル）

ES Modules を使用するため、**`file://` の直開きは動作しません**。ローカルサーバー経由で開いてください。

```bash
# このフォルダ（docs/）で実行
python -m http.server 8000
# → ブラウザで http://localhost:8000/ を開く
```

Node 環境の場合は `npx serve` や `npx http-server` でも動作します。

### 操作（PC）

- **マウス移動**：Quad が傾く（カメラは固定。傾けることで視差とホログラムが動く）
- **左ドラッグ**：画面移動（Pan）
- **ホイール**：ズーム
- **スペースキー**：画面上の UI（右上パネル / 左上タイトル / 左下ヒント）の表示 / 非表示切替
- **右上パネル（lil-gui）**：
  - イラスト：`背景`〜`レイヤー3` の 4 スロット。ボタンから画像を選択して差し替え
  - 全体の奥行き感**：全体の奥行き量
  - 各レイヤーの奥行き感：0 で効果無効、1 で効果最大
  - ホログラムを ON：ホログラム表現の ON/OFF

### 操作（スマートフォン）

タッチ端末では自動的にモバイルモードに切り替わります。

- **端末を傾ける**：Quad が傾く（起動時の姿勢が中心となる）
- **1本指ドラッグ**：画面移動（Pan）
- **2本指ピンチ**：ズーム
- **◐ ボタン（右上）**：画面上の UI（上部タイトル / パネル）の表示 / 非表示切替
- **下部ドロワー（ハンドル）**：タップで操作パネルを開閉
  - イラスト：`背景`〜`レイヤー3` の 4 スロット。ボタンから画像を選択して差し替え
  - 全体の奥行き感：全体の奥行き量
  - 各レイヤーの奥行き感：0 で効果無効、1 で効果最大
  - ホログラムを ON：ホログラム表現の ON/OFF
- **iOS Safari の初回起動**：ジャイロ利用のために許可ダイアログが表示されます。「ジャイロを有効にする」をタップして許可してください。



### テクスチャについて

- 起動時は 背景に canvas 生成の 1 枚絵が入っています。
- レイヤーは 奥 → 手前順に：`背景` → `レイヤー1` → `レイヤー2` → `レイヤー3`。
- 入力する画像は全て同解像度に揃えるのが好ましいです。
- 手前のレイヤーは透過PNG推奨。背景は不透明で問題ありません。
- **Quad のアスペクト比は背景にセットした画像に吸着します。**
  - 長辺上限 2048px / 短辺下限 320px。短辺不足の画像は読み込めません
- `レイヤー1`〜`レイヤー3` は `背景`の 解像度に正規化されます
  - 大きい場合は縮小、小さい場合は中央に配置されます。
- ホログラム用ドットは `assets/dot.png`・`assets/dot2.png` が固定ロードされます。


### 注意点

- **WebGL2**：`GLSL ES 3.0`（`RawShaderMaterial` + `THREE.GLSL3`）を使用しています。
最近のブラウザであれば問題なく動きます。
- **CDN 依存**：three.js（unpkg）と lil-gui（jsDelivr）を importmap 経由で読み込みます。
オフライン環境では動作しません。ローカルに落として使う場合はパスを差し替えてください。
- **モバイル動作**：動作可能ですが、高解像度テクスチャは端末により重くなる場合があります。
- **テクスチャサイズ**：WebGL の `MAX_TEXTURE_SIZE`（多くの端末で 4096 または 8192）を超える画像は表示できません。
長辺 2048px 程度が推奨。
